DA INTUIÇÃO À APLICAÇÃO

Uma recomendação.
Cinco decisões.

Esta é uma demonstração de recomendação baseada em conteúdo. Cada filme é representado pelo texto de sua descrição.

01

Transformar linguagem em dados

O sistema coloca o texto em minúsculas, remove acentos e pontuação e ignora palavras frequentes, como “de” e “uma”. Cada termo restante ocupa uma posição no vocabulário de todo o catálogo. Não usamos o título, o ano ou a categoria no cálculo.

“Uma missão espacial.” → [missao, espacial]

Não há lematização: “piloto” e “pilotos” continuam sendo termos diferentes. Essa limitação é visível no laboratório.

02

Dar um peso a cada palavra

TF conta as ocorrências no texto. IDF aumenta o peso das palavras raras no catálogo. A descrição se torna um vetor TF-IDF, normalizado para comprimento 1, para que textos maiores não ganhem apenas por serem maiores.

idf(t) = ln((1 + N) / (1 + df(t))) + 1
peso(t, filme) = contagem(t, filme) × idf(t)
v = peso / ||peso||₂

N é o total de filmes; df(t) conta em quantos filmes o termo aparece. A suavização com +1 evita divisões problemáticas.

03

Resumir o seu histórico

Tiramos a média dos vetores dos filmes marcados como vistos e apreciados. Depois normalizamos novamente. Esse vetor representa o perfil. Todos os favoritos têm o mesmo peso e são excluídos dos candidatos.

perfil = normalizar((v₁ + v₂ + … + vₖ) / k)

Histórico vazio não tem direção: o site pede filmes em vez de inventar recomendações. Misturar gostos muito diferentes pode diluir cada preferência.

04

Medir o ângulo entre as histórias

O produto escalar mede o alinhamento. Dividi-lo pelos comprimentos produz o cosseno. O arco cosseno converte o resultado em um ângulo, exibido em graus como na demonstração em sala.

s = (a · b) / (||a||₂ × ||b||₂)
θ = arccos(s) × 180 / π
distância do cosseno = 1 − s
ÂnguloSimilaridadeDistânciaLeitura
0°10Mesma direção
60°0,50,5Alinhamento parcial
90°01Ortogonalidade

No TF-IDF, as coordenadas são não negativas: o intervalo vai de 0° a 90°. Embeddings neurais podem conter coordenadas negativas; o intervalo geral é 0°–180°, com cosseno entre −1 e 1 e distância entre 0 e 2.

Histórias parecidas não precisam chegar perto de 0° em termos absolutos. O que determina a ordem é terem ângulos menores que os outros candidatos.

05

Ordenar, explicar e avaliar

Comparamos o perfil a todos os filmes não vistos e ordenamos pelo menor ângulo, equivalente ao maior cosseno. Em empates, o ID do catálogo define uma ordem estável. Os termos em comum explicam contribuições no TF-IDF, não causalidade ou gosto garantido.

Uma plataforma real pode combinar conteúdo, comportamento de usuários, diversidade e contexto. Este site demonstra uma dessas peças; não reproduz o algoritmo proprietário de um serviço.

Em produção: gerar vetores em lote, indexar candidatos, atualizar o perfil, recuperar vizinhos, reordenar e avaliar. Use divisões temporais dos dados, Recall@K e NDCG@K com interações futuras, além de diversidade e testes controlados. Não há usuários reais nem métricas de acurácia neste catálogo.

Por que não recomendar só pela categoria?

Dois filmes de ficção científica podem falar de assuntos bem diferentes. Aqui, temas como “memórias”, “realidade simulada” ou “missão espacial” emergem das descrições. O resultado depende de como elas foram escritas; as sinopses curtas deste catálogo são uma simplificação didática.

ABERTO PARA EXPLORAR

Do navegador

Um projeto estático, em português, sem chave de API e sem cadastro. Execute localmente, estude o código e publique com GitHub Pages.

Baixar projeto completo

Publicação em três passos

  1. Extraia o ZIP e envie os arquivos para um novo repositório no GitHub.
  2. Em Settings → Pages → Source, escolha GitHub Actions.
  3. Execute o workflow Deploy GitHub Pages. Ele publica a pasta dist/ e fornece a URL do site.

O README inclui execução local, testes, estrutura, fórmulas e instruções de extensão. O site usa caminhos relativos, compatíveis com páginas de repositórios.

Este botão baixa o código; ele não cria nem publica um repositório na sua conta.

Um Transformer como extensão

O script Python usa paraphrase-multilingual-MiniLM-L12-v2, da família Sentence Transformers, adequado à comparação semântica de frases em vários idiomas, incluindo português.

pip install -r requirements-transformer.txt
python scripts/generate_embeddings.py

Depois, carregue embeddings.json no Laboratório. O cálculo e o ranking usam os vetores importados. A primeira geração baixa o modelo; não foi pré-executada nesta entrega.

O Transformer muda a representação, não a fórmula do cosseno. Dimensões neurais não equivalem a palavras individuais.

Dados, artes e privacidade

217 filmes e 18 recortes temáticos, de 1980 a 2026. Anos de lançamento original; títulos podem variar entre países. Descrições curtas redigidas para esta demonstração, sem copiar sinopses de plataformas.

Capas tipográficas e motivos vetoriais são artes editoriais próprias, não cartazes oficiais. A imagem da Terra é da NASA / Suomi NPP, PIA18033. Nenhuma afiliação com estúdios.

Favoritos ficam no armazenamento local deste navegador. Não há cadastro, rastreamento ou envio do histórico a um servidor. “Limpar histórico” apaga os favoritos locais.
